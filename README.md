# Senate Votes on Energy Permitting and Spending

Public record of former Senator Joe Manchin’s votes and positions on energy permitting reform, major federal spending packages, and related regulatory questions, set beside the question a voter using the mapping strategy would ask.

This is an applied example only. It does not assess motives or overall alignment with any party or administration.
